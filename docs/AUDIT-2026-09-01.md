## 1. Verdict

**Agree with the headline.**  DealDex looks like a finished listing desk.  It is a working scrape-and-score prototype with a live integrity problem: `/install` was still offering a 17.8 MB APK that the page itself called unsafe.

**Dispute the afternoon “zero deals” as a permanent product failure.**  A live guest scan on this pass returned **All 32 / Deals 4 / Verified Steals 1**.  The desk *can* find under-book asks on a blank “pokemon” query.  Zero-deal passes still happen (market slice + guest free desks).  The bug is the missing empty-state, scrape order, auto-scan cost, and guest-honesty line — not “the matcher never finds a deal.”

**Do not treat polish as ship-ready.**  Android has no camera, no Play pipeline, and until this lane no public APK should exist.  iOS TestFlight exists; the VisionKit scanner is still unproven on a physical card.  Docs still contradict production.

## 3. What must not be broken

Keep the playbook invariants:

- `/api/native/scan` **refuses** a `keys` payload with 400.
- Website scan may send browser-saved keys; `/privacy` must say so.  Phone apps scan paid desks on device.
- Native sign-in is PKCE + single-use `state` + tap-to-handoff HTML.  No automatic `dealdex://` 302.
- `MIN_MATCH_SCORE = 40`.  Steal ≥ 30% under book, good ≥ 12%.  Do not retune to inflate Deals.
- Hide Proxies default on.
- Web CI is `npm ci` + lint + typecheck + test + build.
- Never edit `~/Code/DealDex`.  Never `--force-ship`.  Never copy an unsigned debug APK to `public/`.

## 5. Mitigation plan (ordered)

The playbook’s wave order is right.  Execute it.  Do not restore `public/DealDex.apk` because `assembleDebug` succeeded.

### Wave 0 — this lane (in flight)

1. **DD-001 / DD-051** — Delete APK and source zip.  Rewrite `/install`.  Gitignore both names.  Tests: no `href="/DealDex.apk"`, `public/` must not contain those files.
2. **DD-010 / DD-011 (partial)** — `public/robots.txt` + `public/sitemap.xml`.
3. **DD-012** — Remove SVG `<title>` from market logos.

**Done when live:** `curl -sI https://dealdex.net/DealDex.apk` is 404.  `/install` has no download.  `GET /robots.txt` is 200 `text/plain`.  Homepage HTML has one `<title>`.

### Wave 1 — SEO / PWA (next PR)

- Title: `DealDex · Find the best-priced Pokémon card listings`
- Canonical `https://dealdex.net/`
- Replace `/__grok/manifest` and `/__grok/icon-180.png` with first-party PNG 180/192/512 and `manifest.webmanifest`
- Gate `grokPwaPlugin` to `serve` if production never needs `/?install=1`

### Wave 2 — desk UX (do not retune thresholds)

- Sort by `appraisal.spread` descending after a successful scan
- Empty-state when `dealCount === 0` (guest free-desk line)
- Short mobile placeholder: `Card, set, or number`
- **Stop auto-scan on first paint.**  Show last local cache; require ⚡ SCAN MARKET.  Also stop `NativePhones` auto-scan (DD-052)
- Guest line: `Free desks only · TCGPlayer / Cardmarket / solds`
- Named-card hunt: extra eBay cheapest pass, merge by listing id, keep `MIN_MATCH_SCORE = 40`

### Wave 3 — backend

- `maxDuration` 60s on the actual Nitro scan function path
- 8–12s abort per upstream; partial rows + `notes`
- Quota that survives two warm instances (cache table / IP hash).  Do not pretend the in-memory map is global
- README: scrape via Jina/Brave, not “eBay API”

### Wave 4 — Android

- `android-ci.yml`: `assembleDebug` + `assembleRelease` on ubuntu, unsigned artifact, **never** copy to `public/`
- R8 keep rules for Tink; force-stop session test on a device
- Camera: ML Kit + CameraX with the iOS contract, **or** all copy stays “iOS-only”
- Package ID stays `me.grok.dealdex` until owner picks DD-047

### Wave 5 — iOS

- After each `ios-ship`, write `MARKETING_VERSION` / `CURRENT_PROJECT_VERSION` back into `project.yml`
- Physical iPhone scanner checklist (owner).  Simulator cannot close DD-018
- Universal Links after Associated Domains + AASA.  Keep tap page.  `dealdex://` debug-only
